## 공개 범위 점검표

- 대상과 목적: 이 페이지는 불특정 다수의 방문자에게 내 가치관, 관심사, 강점을 소개하기 위한 것입니다.
- 공개할 것: 이름, 이메일, 성향 정보(핵심 가치·관심사·강점·작동 방식)
- 공개하지 않을 것: 전화번호, 집 주소, 소속(학교·직장), 개인 목표·일정표(학습 계획, 자격증 일정 등)

## 짧은 확인 방법

- 위치: https://terran1234.github.io/about-me/
- 행동: 페이지 접속 → 상단 내비게이션에서 "연락처" 클릭 → 해당 섹션으로 스크롤 이동 확인
- 통과 모습: 부드럽게 스크롤되며 이름("조경익")과 이메일("ruddlr5141@naver.com")이 텍스트로 표시됨. 로그인 요구 없이 바로 보임
- 안 될 때 모습: 페이지가 빈 화면이거나, 클릭해도 이동하지 않거나, 접속 시 로그인/에러 화면이 뜸

## AI와 나의 판단

- AI에게 맡긴 일: HTML/CSS 코드 작성, GitHub repo 생성·Pages 배포, 여러 디자인 시안 제작
- 직접 판단한 일: 페이지의 핵심 내용(핵심 가치, 관심사, 강점 등)은 내가 미리 정리해둔 자기소개 자료를 바탕으로 직접 작성·제공했고, 공개 범위(이름·이메일만), 공개할 내용 선별(개인 목표·계획표는 제외), 최종 디자인 방향(흰 배경 + 솔리드 컬러)도 직접 결정
- AI 제안을 따르지 않은 일: 처음 제안한 그라데이션 텍스트 스타일이 가독성을 떨어뜨린다고 판단해 거절하고 솔리드 컬러로 변경 요청
