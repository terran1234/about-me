## AI와 나의 판단

- AI에게 맡긴 일: HTML/CSS 코드 작성, GitHub repo 생성·Pages 배포, 여러 디자인 시안 제작
- 직접 판단한 일: 페이지의 핵심 내용(핵심 가치, 관심사, 강점 등)은 내가 미리 정리해둔 자기소개 자료를 바탕으로 직접 작성·제공했고, 공개 범위(이름·이메일만), 공개할 내용 선별(개인 목표·계획표는 제외), 최종 디자인 방향(흰 배경 + 솔리드 컬러)도 직접 결정
- AI 제안을 따르지 않은 일: 처음 제안한 그라데이션 텍스트 스타일이 가독성을 떨어뜨린다고 판단해 거절하고 솔리드 컬러로 변경 요청
